Accessibility

We want everyone to be able to use our website.

AACA aims to make this website easy to use for everyone. We design our pages to meet the Web Content Accessibility Guidelines (WCAG) 2.2 Level AA.

  • Clear, plain English
  • Good colour contrast and readable text sizes
  • Descriptions for images
  • Pages that work with a keyboard and on mobile phones

If you have difficulty using any part of this website, please email admin@aacansw.org.au or call 0488 884 372 and we will help.
